# Acessibilidade

A referência web é WCAG 2.2 AA, complementada pelas APIs nativas de cada plataforma. Todo fluxo
principal deve funcionar por teclado e leitor de tela, não depender exclusivamente de cor, som,
gesto ou movimento, possuir foco visível e respeitar redução de movimento.

Checklist de release: ordem de foco; nomes, funções e estados acessíveis; contraste; escala de texto;
legendas; alternativas para voz/toque; alvos adequados; linguagem simples; erros anunciados; testes
com Narrator no Windows e TalkBack/Voice Access/Switch Access no Android.
